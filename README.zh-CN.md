## ✨ 功能

**多开与登录**

- **一键多开** —— 勾选账号，按你排好的顺序逐个打开，自动解除多开限制
- **支持 OTP 验证器** —— 在手机上批准一次，之后直接启动
- **分组** —— 常一起玩的账号一键勾选

**每个账号可以单独设置**

- **登录地区、窗口模式、静音、MOD、额外参数**
- **画面与性能** —— 窗口分辨率、帧率上限、CPU 优先级。后台账号锁低帧率、把优先级设低，资源留给主力账号
- **窗口改名** —— 游戏标题改成账号名称，多开时不会认错

**其他**

- **免安装** —— 一个 exe，不用另外装 .NET
- **屏幕隐私** —— 账号自动打码；密码与 Token 用 Windows 加密保存在本机
- **迷你窗口** —— 常驻的小列表，一眼看出哪些开着，点一下切换或补开；可以拖边调整大小
- **用量看得到** —— 运行中的账号显示 CPU 与内存，还有整张显卡的显存用量，多开前先看有没有吃满
- **快捷键** —— 每个账号一组，按下直接切到那个游戏
- **右下角图标** —— 点击关闭时可以选择收到任务栏右下角的通知区域，程序继续运行
- **多语言界面** —— 繁體中文、简体中文、English、한국어，点击左下角的地球图标或顶部的“语言”菜单就能切换
- **检查新版本** —— 有新版会提示，不会自动下载或安装，可关闭

## 🚀 快速开始

1. 打开 Nexus，Windows 请求管理员权限时点击“是”。
2. Nexus 会自动找到游戏。活动记录里没有出现“已找到游戏”的话，到左侧“全局设置”点击“自动查找”，还是找不到就点击“浏览游戏主程序…”选择 `D2R.exe`。
3. 回到“账号总览”，修改示例账号或点击“＋ 添加账号”，填入账号、密码、登录地区。
4. 绑定了验证器的账号，勾选“使用 Token 登录”，点击“获取 Token”后在手机上批准一次。
5. 勾选要打开的账号，点击“启动所选”。

拖动账号左侧的 ≡ 调整启动顺序；亮起的“沿用全局”表示该项使用全局设置，点一下改成这个账号单独的设置。

> 💡 多开时，把后台账号的**帧率上限**调低、**CPU 优先级**设成“低”，主力账号会流畅一点。

### Token 账号的启动顺序

```mermaid
flowchart LR
    A["按“启动所选”"] --> B{"这个账号怎么登录？"}
    B -->|账号密码| C["开游戏，游戏自动登录"]
    C --> D["不用等，接着开下一个"]
    B -->|Token| E["写入 Token，开游戏"]
    E --> F["停在“按任意键即可开始”"]
    F --> G["你按一下键，游戏登录"]
    G --> H["Token 被读走，换下一个"]
```

Windows 一次只存得下一个 Token，所以两个 Token 账号不能同时开：**前一个没有在游戏窗口按键登录，后面的账号就会一直等**（活动记录会写出它在等谁、等了几秒）。用账号密码登录的账号会自己登录，不受影响。

### 迷你窗口

玩的时候把主窗口收成一条小列表，放在屏幕角落：

![迷你窗口](docs/images/mini.zh-CN.png)

绿点表示游戏开着（点一下切过去），灰点表示没开（点一下就启动），橙点表示游戏没有响应（右键可以结束它）。旁边是这个账号占用的 CPU 与内存。

账号多的时候列表会很长：不想出现在这里的账号，在那一行按右键选“不要显示在这里”，或到账号设置取消勾选“显示在迷你窗口”。列表下方会写还有几个没显示、其中几个正在跑，点旁边的箭头就能展开，点一下把账号放回列表。被隐藏的账号照常启动，快捷键也照常用。

开着的账号会排在列表最前面，账号多的时候不用滚到下面找；不想这样的话，在面板上按右键取消“运行中的排在最前面”。窗口可以拖边调整大小，列表放不下就会滚动。最下面一行是**整张显卡**的显存用量，收起成小条时显示百分比，用掉九成以上会变色；账号总览的每一行也会显示那个账号占用的 CPU 与内存。

## 🛡️ 不是外挂

Nexus 只是帮你打开游戏的管理工具，**不注入程序、不读写游戏内存、不修改游戏文件、不拦截网络连接、不挂机打怪捡物、不绕过验证、不上传你的数据**。每一项做法、需要的权限和连接对象都写在[安全说明](SECURITY.zh-CN.md)里。

只有一个例外，**v0.5.0 才加的，而且默认是关闭的**：**自动按掉开场画面**（v0.4.6 以前没有这个功能，Nexus 不会送出任何按键）。用 Token 登录的游戏会停在“按任意键即可开始”等人按一下，开启后由 Nexus 送出一个空格键替你按掉，只送给 Nexus 自己启动的那个游戏窗口，登录完成就停。这是程序替你操作游戏，所以开启前会先弹出说明窗口、倒数五秒才能按同意，同意的时间与当时的内容会留在你自己的电脑上，不会上传到任何地方。不开启的话，Nexus 一个按键都不会送出，也不会记录你按了什么。

**而且这个开关是每个账号各自独立的。** 全局开启之后，个别账号仍然可以单独关掉：把主账号、仓库号留在这个功能之外，真的出了什么事，没用过的账号不会跟着一起。账号单独开启时一样要再同意一次。

多开与第三方工具是否符合规定，最终以 Blizzard 的使用条款与判定为准，Nexus 无法保证账号不会受到任何处罚；开启自动按键等于自己多担一份风险，请先衡量再决定。

## ❓ 常见问题

<details>
<summary>连接 Battle.net 时显示“无法验证”</summary>

游戏已经打开，是 Battle.net 拒绝登录，和多开无关。请依次确认：

1. 账号绑定了验证器 → 改用“使用 Token 登录”并获取 Token
2. 密码是否正确（改过密码要重新输入）
3. 登录账号（Email）有没有输错
4. 使用 Token 的账号，重新绑定过验证器的话，点击“清除”再重新获取
5. 先用 Battle.net 启动器登录一次，完成安全验证后再试
</details>

<details>
<summary>一直卡在“连接到 Battle.net”</summary>

游戏已经打开、多开也成功了，是登录时 Battle.net 没有响应。请依次试试：

1. 关掉游戏，用 Battle.net 启动器登录这个账号一次，有“我不是机器人”之类的验证就做完，等一段时间再打开。短时间内登录太多次或输错几次密码，Battle.net 会要求验证，而用 Nexus 打开的游戏没有地方做验证，就可能一直卡着
2. 开了 VPN 或加速器的话，先关掉再试
3. 从 Battle.net 启动器打开游戏也卡住，就是网络或服务器的问题，和多开无关

还是不行的话，请到 Issues 反馈，附上登录方式（账号密码或 Token）、从第几个账号开始卡住，以及日志。
</details>

<details>
<summary>亚洲可以玩，换欧洲或美洲就说无法连上服务器</summary>

用账号密码登录时会这样，那个账号改用 Token 登录就正常（板友反馈，亚洲不受影响）。

到账号设置把“登录地区”改成欧洲或美洲，勾“使用 Token 登录”，再按“获取 Token”在手机上批准一次。**Token 是分地区的**，换地区要重新获取；获取的 Token 和登录地区不同时，活动记录会提醒你。
</details>

<details>
<summary>用 Token 登录的账号，进游戏只能离线？</summary>

那个 Token 失效了。改过 Battle.net 密码、重新绑定或停用验证器都会让它失效。

到账号设置的“登录 Token”按“清除”，再按一次“获取 Token”，在手机上重新批准。没绑验证器的账号，也可以取消勾选“使用 Token 登录”，改用账号密码登录。
</details>

<details>
<summary>用 Token 登录的账号，开起来停在“按任意键即可开始”</summary>

这是游戏本身的行为：用 Token 启动时，游戏会先停在开场画面，**在那个窗口按任意键**才会开始登录。用账号密码登录的账号会自己登录，不用按。

有多个 Token 账号时这一步更重要：Windows 一次只放得下一个 Token，**前一个账号登录之后才轮得到下一个**。所以你没去按的话，后面的账号会一直等（活动记录会写出它在等什么、等了多久）。启动后先把每个 Token 账号的窗口按一下，后面就会接着开。

全局设置的“登录协助”可以让这一步轻松一点：**Token 账号的游戏窗口出现时叫到最前面**默认就是开的，你不用自己去找窗口。真的不想一个一个按的话，同一张卡片里有**自动按掉开场画面**，开启后由 Nexus 替你按下去；那是程序替你操作游戏，所以默认关闭，开启前会先把做了什么说清楚并要你按下同意，请自己衡量风险。

只让部分账号使用的话，Nexus 会把**没开自动按键的 Token 账号排到最后才启动**，其他账号才不会卡在它后面等你去按；代价是那个账号会变成最后一个开。这件事发生时活动记录会写出来。
</details>

<details>
<summary>用 Apple、Google 等方式登录，没有 Battle.net 密码</summary>

获取 Token 的页面只接受 Email 和密码。请在登录窗口点击右上角的“用其他方式登录”，用平时的方式登录后再点击“完成登录”。步骤见[用 Apple、Google 等方式登录（繁体中文）](docs/apple-login.md)。
</details>

<details>
<summary>Nexus 会改动我在游戏里调好的设置吗？</summary>

只会写入你在“画面与性能”里设置的**窗口分辨率**和**帧率上限**，其他游戏设置（画质、音量、自动地图、按键…）完全不碰。游戏的帧数限制取“帧率上限”和“动态分辨率调节”的“目标帧数”里较大的那个，所以目标帧数高于上限时，Nexus 会把它降到同一个数字。

这两项由 Nexus 决定，所以在游戏里改了之后，下次启动会被账号的设置覆盖。想把游戏里调好的值作为默认值，到“全局设置 → 画面与性能”点击一次“读取当前游戏设置”。
</details>

<details>
<summary>帧率上限设了，实际帧数却不一样？</summary>

先看游戏“显示设置”的**垂直同步**。开着的时候，实际帧数只会落在屏幕刷新率的整除值上：60Hz 的屏幕就是 60、30、20、15，所以设 36 或 45 实际会跑 30。想完全按数字跑就把垂直同步关掉。

另一个是“动态分辨率调节”的**目标帧数**，游戏会取它和帧率上限里较大的那个。v0.4.3 起 Nexus 会在需要时把它一起降下来，更旧的版本请自己在游戏里确认那个值。
</details>

<details>
<summary>CPU 优先级有什么用？</summary>

多开时大家一起抢 CPU，把后台账号设成“低”，主力账号就会先用到 CPU，卡顿会少一点。

要注意它**不会让 CPU 使用率变低**，只是决定谁先用。如果你开的数量不多、CPU 没有占满，设了也感觉不到差别，保持“正常”就好。
</details>

<details>
<summary>多开很卡，或者一次开太多开不起来？</summary>

Nexus 只负责把游戏开起来，开起来之后不会占用性能，卡顿是几个游戏一起跑造成的。后台挂着的账号三项一起设才有感觉：

1. **帧率上限** 设 15 或 30
2. **CPU 优先级** 设“低”，让主力账号先用到 CPU
3. **窗口分辨率** 设 1280x720

一次开很多个时，前一个还在读取就被下一个挤住的话，到“全局设置 → 启动与诊断”把“各账号启动间隔”调成 5～10 秒。
</details>

<details>
<summary>快捷键会记录我按了什么吗？</summary>

不会。Nexus 是向 Windows **注册**你指定的组合键，只有你按下那一组时 Windows 才会通知它，其他按键完全收不到。这和会拦截所有按键的“键盘钩子”是两回事，Nexus 没有使用后者。

也正因为组合键是向系统注册的，这一组在 Nexus 运行期间不会传给其他程序，所以设置时一定要包含 Ctrl、Alt 或 Win，不要用游戏本身会用到的单键。
</details>

<details>
<summary>关掉窗口以后程序还在运行？</summary>

点击关闭时可以选“收到右下角”，Nexus 就会继续在后台运行，点击任务栏右下角的图标能调出来，右键菜单里有“显示主窗口 / 退出”。

这个选择可以记住，之后想改，到“全局设置 → 窗口 → 点击关闭时”。点最小化则和一般程序一样，留在任务栏上。
</details>

<details>
<summary>为什么需要管理员权限？</summary>

解除多开限制需要，打开时只问一次。拒绝也能使用，只是每次都要再问。游戏会随之以管理员权限运行，OBS、Discord 可能也要以管理员身份运行才能捕获画面。
</details>

<details>
<summary>账号密码保存在哪里？</summary>

在你电脑上的 `%LOCALAPPDATA%\D2RNexus`，密码与 Token 用 Windows 内置加密保存，不会上传。用账号密码登录时，密码会传给游戏的启动参数；Token 登录则不会。
</details>

<details>
<summary>显示“窗口就绪”代表登录成功吗？</summary>

不一定。Nexus 只能确认窗口出现，无法判断是否登录完成，请以游戏画面为准。
</details>

<details>
<summary>窗口分辨率最小可以设多少？</summary>

列表里是游戏支持的窗口大小，也可以选“自定义”。建议最小 1280x720，再小的话游戏不会等比例缩小，而是直接裁掉画面（物品栏、快捷栏可能看不到）。
</details>

<details>
<summary>关掉 Nexus 会关掉游戏吗？</summary>

不会。重新打开 Nexus 后仍能认出之前打开的游戏，不会让同一个账号重复启动。
</details>

<details>
<summary>更新到新版本，设置会不会不见？</summary>

不会。更新就是把旧的 `D2RNexus.exe` 换成新的，账号、群组、画面设置都放在另一个文件夹，新版会直接接着用，不需要重新设置。

想自己留一份的话，用上方菜单的“帮助 → 打开设置文件夹”，把整个文件夹复制起来就是备份。**换电脑或换 Windows 用户时，密码和登录 Token 要重新输入**：那两个文件是用 Windows 的加密绑在原本那台机器的那个用户上，复制过去也解不开。
</details>

<details>
<summary>如何彻底移除？</summary>

删除 `D2RNexus.exe` 与文件夹 `%LOCALAPPDATA%\D2RNexus`。用过窗口分辨率设置的话，游戏设置文件夹里的 `Settings.json.nexus-backup` 也可以删除。
</details>
