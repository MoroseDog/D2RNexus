## 로그인과 접속

### Battle.net에 연결할 때 인증할 수 없다는 메시지가 나옵니다

게임은 이미 열렸고, Battle.net이 로그인을 거부한 것이므로 다중 실행과는 관계가 없습니다. 다음을 차례대로 확인하세요.

1. 계정에 인증기가 연결되어 있다면 → '토큰으로 로그인'으로 바꾸고 토큰을 받으세요
2. 비밀번호가 맞는지 (비밀번호를 바꿨다면 다시 입력해야 합니다)
3. 로그인 계정(이메일)을 잘못 입력하지 않았는지
4. 토큰을 쓰는 계정이 인증기를 다시 연결했다면 '지우기'를 누른 뒤 토큰을 다시 받으세요
5. Battle.net 런처로 먼저 한 번 로그인해 보안 인증을 마친 뒤 다시 시도하세요

### Battle.net에 연결하는 단계에서 계속 멈춰 있습니다

게임은 이미 열렸고 다중 실행도 성공했지만, 로그인할 때 Battle.net이 응답하지 않는 상황입니다. 다음을 차례대로 시도해 보세요.

1. 게임을 닫고 Battle.net 런처로 이 계정에 한 번 로그인하세요. '로봇이 아닙니다' 같은 인증이 나오면 끝까지 완료하고, 잠시 기다린 뒤 다시 여세요. 짧은 시간에 로그인을 너무 많이 하거나 비밀번호를 몇 번 틀리면 Battle.net이 인증을 요구하는데, Nexus로 연 게임에는 인증을 할 곳이 없어서 계속 멈춰 있을 수 있습니다
2. VPN이나 게임 가속기를 켜 두었다면 끄고 다시 시도하세요
3. Battle.net 런처로 게임을 열어도 멈춘다면 네트워크나 서버 문제이며, 다중 실행과는 관계가 없습니다

그래도 안 되면 Issues에 로그인 방식(계정/비밀번호 또는 토큰), 몇 번째 계정부터 멈추는지, 그리고 로그를 함께 올려 주세요.

### 아시아는 되는데 유럽이나 아메리카에서는 서버에 연결할 수 없다고 나옵니다

계정과 비밀번호로 로그인할 때 생기는 문제이며, 그 계정을 토큰 로그인으로 바꾸면 정상적으로 됩니다. 아시아는 영향을 받지 않습니다.

계정 설정에서 '로그인 지역'을 유럽이나 아메리카로 바꾸고 '토큰으로 로그인'을 체크한 뒤 '토큰 받기'를 눌러 휴대폰에서 한 번 승인하세요. **토큰은 지역별로 다르므로** 지역을 바꾸면 다시 받아야 합니다. 받은 토큰이 로그인 지역과 다르면 활동 기록이 알려 줍니다.

### 토큰으로 로그인한 계정이 오프라인으로만 들어가집니다

그 토큰이 만료된 것입니다. Battle.net 비밀번호를 바꾸거나 인증기를 다시 연결하거나 해제하면 토큰이 무효가 됩니다.

계정 설정의 '로그인 토큰'에서 '지우기'를 누른 뒤 '토큰 받기'를 다시 눌러 휴대폰에서 한 번 더 승인하세요. 인증기를 연결하지 않은 계정이라면 '토큰으로 로그인' 체크를 해제하고 계정과 비밀번호로 로그인해도 됩니다.

### 토큰으로 로그인한 계정이 '아무 키나 누르십시오' 화면에서 멈춥니다

게임 자체의 동작입니다. 토큰으로 실행하면 게임이 시작 화면에서 멈추고, **그 창에서 아무 키나 눌러야** 로그인을 시작합니다. 계정과 비밀번호로 로그인하는 계정은 알아서 로그인합니다.

토큰 계정이 여러 개라면 이 단계가 더 중요합니다. Windows에는 토큰이 한 번에 하나만 저장되므로 **앞 계정이 로그인해야 다음 계정이 실행됩니다**. 키를 누르지 않으면 뒤의 계정은 계속 기다립니다(활동 기록에 무엇을 얼마나 기다리는지 표시됩니다). 창이 뜰 때마다 아무 키나 눌러 주면 나머지가 이어서 실행됩니다.

전역 설정의 '로그인 도우미'를 쓰면 이 단계가 한결 편해집니다. **토큰 계정의 게임 창을 맨 앞으로 가져오기**는 기본값이 켜짐이라 창을 직접 찾을 필요가 없습니다. 아예 직접 누르고 싶지 않다면 같은 카드에 **시작 화면 대신 눌러 주기**가 있어 Nexus가 대신 눌러 줍니다. 이는 프로그램이 게임을 대신 조작하는 것이므로 기본값은 꺼짐이며, 켜기 전에 무엇을 하는지 알려 주고 동의를 받습니다. 위험은 스스로 판단해 주세요.

일부 계정만 사용하는 경우, Nexus는 **자동 키 입력이 꺼진 토큰 계정을 마지막에 실행합니다.** 그래야 나머지 계정이 사람을 기다리는 계정 뒤에서 멈추지 않습니다. 대신 그 계정은 가장 마지막에 열립니다. 이렇게 되면 활동 기록에 표시됩니다.

### Apple, Google 등으로 로그인해서 Battle.net 비밀번호가 없습니다

토큰을 받는 페이지는 이메일과 비밀번호만 받습니다. 로그인 창 오른쪽 위의 '다른 방법으로 로그인'을 눌러 평소 방법으로 로그인한 뒤 '로그인 완료'를 누르세요. 자세한 단계는 [Apple, Google 등으로 로그인하기 (중국어)](apple-login.md)를 참고하세요.

### '창 준비됨'이 표시되면 로그인에 성공한 건가요?

꼭 그렇지는 않습니다. Nexus는 창이 나타났는지만 확인할 수 있고 로그인이 끝났는지는 판단할 수 없으니, 게임 화면으로 확인하세요.

## 게임 설정

### Nexus가 게임 안에서 바꾼 설정을 건드리나요?

계정 설정의 '게임 설정'에서 고른 것만 기록합니다. **창 해상도**, **프레임 제한**, 그리고 그 계정이 쓰는 **화질**과 **사운드** 설정 그룹입니다. 다른 게임 설정(자동 지도, 키 설정, 조작 등)은 전혀 건드리지 않습니다.

화질과 사운드의 기본값은 '현재 설정'입니다. 게임이 지금 쓰는 값을 그대로 두고 실행할 때 아무것도 쓰지 않는다는 뜻입니다. 특정 계정을 어떤 화질로 고정하려면 '전역 설정 → 게임 설정'에서 '설정 그룹 관리…'를 눌러 한 벌 복사한 다음, 계정 설정에서 그 그룹을 고르세요.

'여러 개를 띄울 때 게임 옵션 고정'을 켜면 한 가지가 더 기록됩니다. 사용자의 게임 옵션(구슬의 숫자 표시, 자동 지도 등)을 모든 계정에 같은 값으로 적용합니다. 여러 개를 띄웠을 때 한 계정에서 바꾼 설정이 다른 계정에 지워지는 문제를 없애기 위한 것입니다. 이 스위치는 기본적으로 꺼져 있으며 켜기 전에는 해당 항목을 건드리지 않습니다.

Nexus가 관리하는 항목은 실행할 때마다 다시 기록되므로, 게임 안에서 바꾸더라도 다음 실행 때 덮어써집니다. 게임에서 맞춰 둔 값을 기본값으로 쓰고 싶다면 '전역 설정 → 게임 설정'에서 '현재 게임 설정 읽기'를 한 번 누르세요. 프레임은 게임이 '프레임 제한'과 '동적 해상도 조절'의 '목표 프레임' 중 더 높은 쪽을 쓰므로, 목표 프레임이 제한보다 높으면 Nexus가 함께 낮춥니다.

### 프레임 제한을 설정했는데 실제 프레임이 다릅니다

먼저 게임 표시 설정의 **수직 동기화**를 확인하세요. 켜져 있으면 실제 프레임은 모니터 주사율을 나눈 값에만 맞춰집니다. 60Hz 화면이라면 60, 30, 20, 15이므로 36이나 45로 설정해도 30으로 돌아갑니다. 숫자 그대로 적용하려면 수직 동기화를 끄세요.

또 하나는 '동적 해상도 조절'의 **목표 프레임**입니다. 게임은 둘 중 더 높은 값으로 프레임을 제한합니다. v0.4.3부터 Nexus가 필요할 때 제한과 함께 낮추며, 이전 버전에서는 게임에서 직접 확인해 주세요.

### CPU 우선순위는 어디에 쓰나요?

여러 개를 실행하면 모든 게임이 CPU를 두고 경쟁합니다. 백그라운드 계정을 '낮음'으로 설정하면 주력 계정이 CPU를 먼저 사용하게 되어 끊김이 조금 줄어듭니다.

단, 이 설정은 **CPU 사용률을 낮추지 않습니다**. 누가 먼저 쓰느냐만 정할 뿐입니다. 실행하는 게임 수가 적어 CPU가 가득 차지 않는다면 설정해도 차이를 느끼지 못하니 '보통'으로 두세요.

### 여러 개를 켜면 버벅이거나, 한 번에 너무 많이 켜면 실행되지 않습니다

Nexus는 게임을 실행해 줄 뿐 실행된 뒤에는 성능을 쓰지 않습니다. 버벅임은 게임 여러 개가 함께 돌아가서 생깁니다. 배경에 띄워 두는 계정은 세 가지를 모두 설정해야 효과가 있습니다.

1. **프레임 제한** 15 또는 30
2. **CPU 우선순위** '낮음'으로 설정해 주력 계정이 CPU를 먼저 쓰게 하기
3. **창 해상도** 1280x720

한 번에 여러 개를 켤 때 앞의 게임이 아직 불러오는 중인데 다음 게임이 겹친다면, '전역 설정 → 실행 및 진단'에서 '계정 간 실행 간격'을 5~10초로 바꾸세요.

### 창 해상도는 얼마나 작게 설정할 수 있나요?

목록에는 게임이 지원하는 창 크기가 있으며, '직접 입력…'을 선택할 수도 있습니다. 최소 1280x720을 권장합니다. 그보다 작으면 게임 화면이 비율에 맞게 줄어들지 않고 그대로 잘려 나갑니다(인벤토리나 단축키 바가 보이지 않을 수 있습니다).

## 프로그램과 데이터

### 단축키가 제가 누른 키를 기록하나요?

아니요. Nexus는 지정한 키 조합을 Windows에 **등록**할 뿐이며, 그 조합을 눌렀을 때만 Windows가 Nexus에 알려 줍니다. 다른 키 입력은 전혀 받지 않습니다. 이는 모든 키 입력을 가로채는 '키보드 후킹'과는 다른 방식이며, Nexus는 키보드 후킹을 사용하지 않습니다.

또한 키 조합을 시스템에 등록하기 때문에, Nexus가 실행되는 동안 그 조합은 다른 프로그램에 전달되지 않습니다. 그러니 설정할 때는 반드시 Ctrl, Alt, Win 중 하나를 포함하고, 게임에서 쓰는 단일 키는 사용하지 마세요.

### 창을 닫은 뒤에도 프로그램이 계속 실행되나요?

닫기 버튼을 누를 때 '알림 영역으로'를 선택하면 Nexus가 백그라운드에서 계속 실행됩니다. 작업 표시줄 오른쪽 아래의 아이콘을 누르면 다시 열 수 있고, 마우스 오른쪽 버튼 메뉴에 '메인 창 표시' / 'D2R Nexus 종료'가 있습니다.

이 선택은 기억해 둘 수 있으며, 나중에 바꾸려면 '전역 설정 → 창 → 닫기 버튼을 누르면'에서 변경하세요. 최소화 버튼을 누르면 일반 프로그램처럼 작업 표시줄에 남습니다.

### 관리자 권한은 왜 필요한가요?

다중 실행 제한을 해제하려면 필요하며, 프로그램을 열 때 한 번만 묻습니다. 거부해도 사용할 수 있지만 매번 다시 묻습니다. 게임도 관리자 권한으로 실행되므로, OBS나 Discord도 관리자 권한으로 실행해야 화면을 캡처할 수 있는 경우가 있습니다.

### 계정과 비밀번호는 어디에 저장되나요?

내 PC의 `%LOCALAPPDATA%\D2RNexus`에 저장됩니다. 비밀번호와 토큰은 Windows 기본 암호화로 보호해 저장하며 업로드하지 않습니다. 계정과 비밀번호로 로그인할 때는 비밀번호가 게임의 실행 인수로 전달되지만, 토큰으로 로그인할 때는 전달되지 않습니다.

### Nexus를 닫으면 게임도 닫히나요?

아니요. Nexus를 다시 열어도 전에 실행한 게임을 알아보기 때문에, 같은 계정이 중복으로 실행되지 않습니다.

### 새 버전으로 업데이트하면 설정이 사라지나요?

아닙니다. 업데이트는 기존 `D2RNexus.exe`를 새 파일로 바꾸는 것뿐입니다. 계정, 그룹, 화면 설정은 별도의 폴더에 있으며 새 버전이 그대로 이어서 사용합니다.

직접 백업하려면 상단 메뉴의 '도움말 → 설정 폴더 열기'를 눌러 폴더 전체를 복사하세요. **다른 컴퓨터나 다른 Windows 사용자에서는 비밀번호와 로그인 토큰을 다시 입력해야 합니다.** 이 두 파일은 만든 사용자에게 묶인 Windows 암호화로 보호되어 다른 곳에서는 열 수 없습니다.

### 완전히 삭제하려면 어떻게 하나요?

`D2RNexus.exe`와 `%LOCALAPPDATA%\D2RNexus` 폴더를 삭제하세요. 창 해상도 기능을 사용했다면 게임 설정 폴더의 `Settings.json.nexus-backup`도 삭제해도 됩니다.
